# 笔迹脉搏 · Handwriting Pulse

笔迹脉搏是一张运行在安卓手机或平板上的数学草稿纸。用手指或手写笔演算时，它按笔记录触点的位置和时间。写完后可以导出 JSON，查看每一笔的轨迹、书写时长和两笔之间的停顿。笔迹采集和文件保存都在本机完成。

## 在安卓真机上运行

电脑准备 Node.js 24.x（24.3.0 或更高）和 npm。本项目已使用 Node.js 24.20.0 与 npm 12.1.0 验证。安卓设备安装与 **Expo SDK 58** 匹配的 Expo Go。让两台设备连接同一可互访的 Wi-Fi。[Android 版 Expo Go](https://expo.dev/go?sdkVersion=58&platform=android&device=true)

```sh
git clone https://github.com/lazytype666/Handwriting-pulse.git
cd Handwriting-pulse
npm install
npm start
```

保持电脑上的开发服务器运行，用 Expo Go 扫描终端二维码。出现白色画布、左上角的「采样诊断」和右下角的「导出」按钮，即可开始书写。已启动安卓模拟器或已连接 USB 调试设备时，也可用 `npm run android` 启动。检查 TypeScript 类型可运行 `npm run typecheck`。

## 书写与诊断

落笔即开始一笔，抬笔结束。在同一笔画中，画布持续跟踪最先落下的触点。诊断区有两个读数。

| 读数 | 如何理解 |
| --- | --- |
| 近 1 秒 | 最近 1000 毫秒实际收到的采样点数。持续移动时可观察事件送达速率。停笔约一秒后归零。 |
| 点间隔 | 最近两个采样点的整数时间戳之差，单位为毫秒。开始时显示「—」，停笔后保留最后一次读数。 |

点「隐藏」收起诊断区，点「显示诊断」重新展开。面板最多约每秒刷新 8 次，隐藏面板或两次刷新之间的书写仍会被采集。要检查设备在连续书写时能否达到 60 点/秒，可从空白页开始，保持笔尖移动至少 10 秒，观察近一秒点数，并保留本次导出文件。实际速率受设备、系统刷新模式和触摸事件分发影响。

## 导出和取出文件

1. 点右下角「导出」。应用将当前全部笔迹写入应用文档目录中的一个新 JSON 文件。居中的「笔迹已导出」窗口显示笔数、点数和可长按选择的完整文件 URI。
2. 要在安卓「文件」应用中查看 JSON，点「另存到手机文件夹」，在系统选择器中选择可写目录并允许使用。完成后即可在所选目录找到副本。取消选择时，原件仍在应用文档目录。
3. 点「返回画布」继续写。下一次导出会包含新增的笔迹。画布保存在当前会话内，离开或重载项目前请先导出。

初次运行可以分三笔写下「1＋」。若分别书写数字、横画和竖画，导出窗口应显示 **3 笔**，JSON 的 `strokes` 中也应有三条记录，每条各有一个 `points` 数组。

## 数据格式与实现

下面用仅含两个触点的一笔说明文件结构。

```json
{
  "meta": {
    "exportedAt": "2026-01-01T00:00:03.000Z",
    "strokeCount": 1,
    "pointCount": 2
  },
  "strokes": [
    {
      "id": 1,
      "points": [
        { "x": 32.5, "y": 48.25, "t": 1767225600000 },
        { "x": 33.5, "y": 49.75, "t": 1767225600017 }
      ]
    }
  ]
}
```

`exportedAt` 为导出时的 UTC 时间。`id` 从 1 开始，按落笔先后编号。`x`、`y` 为相对于应用窗口的坐标，单位为 React Native 逻辑像素。`t` 为映射到 Unix 时间的整数毫秒。

- **采集**。自研的笔画分组、时间戳处理和滑窗统计位于 [src/capture](src/capture/)。开源 Gesture Handler 提供触摸事件，Reanimated 和 Worklets 使采集回调在 UI 线程运行。当前事件接口未提供可依赖的逐点硬件时间戳，因此在回调入口取单调时钟，在首次采样时对齐系统时间。整数毫秒发生碰撞时，后一个点使用下一个可用毫秒，使整次会话的时间戳严格递增。采样率使用取整前的送达时间计算。
- **绘图**。开源 Skia 按屏幕帧绘制当前轨迹。绘图刷新与采样分别执行，导出数据只包含实际送达的触点。
- **存储**。[src/export](src/export/) 使用开源 expo-file-system 将采集快照写入临时文件，写完后在同目录改名。安卓用户可通过系统文件选择器另存副本。
