# Handwriting-pulse

## 简介

本项目仓库用于存放与笔迹脉搏（Handwriting Pulse）相关的软件工程代码。

## 开始使用

```bash
git clone https://github.com/lazytype666/Handwriting-pulse.git
cd Handwriting-pulse
```

## 目录结构

```
.

├── LICENSE                  # MIT 许可证
└── README.md
```

## 参与贡献

欢迎参与本项目！开始之前请阅读 [贡献指南](CONTRIBUTING.md)。

协作流程简述：

1. 从 `main` 创建功能分支（如 `feature/xxx`）；
2. 提交改动并推送到自己的分支；
3. 发起 Pull Request，填写 PR 模板；
4. 合并方式为 **Squash merge**，合并后分支自动删除。
